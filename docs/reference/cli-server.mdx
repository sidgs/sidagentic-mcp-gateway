These commands operate on the Mcpgateway server process itself rather than on its registry contents. `start` launches the gateway, `init-server` prepares it for enterprise use, and `version` reports what is running.

## `start`

Starts the Mcpgateway HTTP server and MCP gateway.

```bash
sami-mcp-gateway start [flags]
```

The server listens on port `8080` by default and exposes the MCP proxy at `/mcp`. On first run, it automatically initializes itself for the selected mode — no additional setup is needed. In enterprise mode on a fresh database, the bootstrap admin access token is printed once to server logs (stdout).

### Flags

<ParamField body="--port" type="string">
  TCP port to bind the HTTP server to. Overrides the `PORT` environment variable. Defaults to `8080`.
</ParamField>

<ParamField body="--enterprise" type="boolean" default="false">
  Start the server in enterprise mode, which enables access control, authenticated clients, and user management. Equivalent to setting `SERVER_MODE=enterprise`. On a fresh database, the server auto-initializes on first start and prints the bootstrap admin access token once to stdout.
</ParamField>

### Environment variables

The `start` command reads environment variables for server mode, database configuration, timeouts, and telemetry. A `.env` file in the working directory is loaded automatically if present.

For the complete list, defaults, and `_FILE` variants, see [Environment variables](/reference/environment-variables).

### Examples

Start in development mode (default):

```bash
sami-mcp-gateway start
```

Start on a custom port:

```bash
sami-mcp-gateway start --port 9000
```

Start in enterprise mode:

```bash
sami-mcp-gateway start --enterprise
```

Start with a Postgres database:

```bash
DATABASE_URL="postgres://user:password@localhost:5432/sami-mcp-gateway" sami-mcp-gateway start
```

## `init-server`

Initializes the Mcpgateway server when running in enterprise mode. This is optional when the server has already auto-initialized on first start — use it to call `POST /init` and save credentials to your local CLI config without copying the bootstrap token from server logs.

```bash
sami-mcp-gateway init-server [--registry <url>]
```

`init-server` creates the first admin user (if the server is not yet initialized) and stores the registry URL and token in `~/.sami-mcp-gateway.conf`, authenticating your CLI as admin.

For the full enterprise bootstrap flow, see [Enterprise operations](/reference/cli-enterprise) and [Access and governance overview](/governance/overview).

### Example

```bash
sami-mcp-gateway --registry http://your-server:8080 init-server
```

## `version`

Prints version information for both the CLI binary and the connected server.

```bash
sami-mcp-gateway version
```

### Output

```text
CLI Version: v1.2.3
Server Version: v1.2.3
Server URL:  http://127.0.0.1:8080
```

If the server is unreachable (for example, when running the CLI without a local server), the server version line is replaced with a message indicating the version could not be retrieved.
