---
title: "Manage Resources"
description: "Inspect and read MCP resources exposed by servers registered in Mcpgateway."
---

When you register an MCP server, Mcpgateway also registers any resources exposed by that server.

Each resource receives a URI that is unique across Mcpgateway. See [Core concepts](/core-concepts#resources) for the resource URI model and how Mcpgateway keeps resources from different servers distinct.

## Get resource metadata

Use the `get resource` command with the resource URI to inspect metadata about a resource:

```bash
# list available resources (useful for discovering resource URIs)
sami-mcp-gateway list resources

sami-mcp-gateway get resource mcpj://res/mintlify-sami-mcp-gateway/bWludGxpZnk6Ly9za2lsbHMvbWNwanVuZ2xl
```

## Read resource contents

Add the `--read` flag to read the resource contents:

```bash
sami-mcp-gateway get resource --read mcpj://res/mintlify-sami-mcp-gateway/bWludGxpZnk6Ly9za2lsbHMvbWNwanVuZ2xl
```

Mcpgateway resolves the URI, routes the request to the upstream MCP server that owns the resource, and returns the resource contents.
