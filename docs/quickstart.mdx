This quickstart guide will show you how to:

1. Start the sami-mcp-gateway server locally using `docker compose`
2. Add the [context7](https://context7.com/) MCP server in sami-mcp-gateway
3. Connect your Claude Desktop to sami-mcp-gateway to access tools

## Start the server

Fetch the `docker-compose.yaml` and start the sami-mcp-gateway server:

```bash
docker compose up -d
```

Use the `docker-compose.yaml` file from this repository. This exposes the streamable HTTP MCP server at `http://localhost:8080/{tenant_id}/mcp` by default (tenant from `DEFAULT_TENANT_ID`, often `sami`).

## Add an MCP server

1. Build or install the `sami-mcp-gateway` CLI from this repository (see [Installation](/installation)).

2. Add the context7 MCP server to sami-mcp-gateway using the CLI:

```bash
sami-mcp-gateway register --name context7 --url https://mcp.context7.com/mcp
```

You should see output similar to this:

  <img src="/images/register-context7.png" alt="register context7 in sami-mcp-gateway" />

<Note>
  SAMI MCP Gateway also includes a Dashboard UI at `http://localhost:8080/`.
  The dashboard is currently in Beta.
</Note>

## Connect to sami-mcp-gateway

In your Claude Desktop, add the configuration for sami-mcp-gateway MCP server:

```json
{
  "mcpServers": {
    "sami-mcp-gateway": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "http://localhost:8080/mcp",
        "--allow-http"
      ]
    }
  }
}
```

Once you have added the configuration, try asking Claude something simple:

```text
Use context7 to get the documentation for `/lodash/lodash`
```

Claude will then attempt to call the `context7__get-library-docs` tool via Mcpgateway, which will return the documentation for the Lodash library.

<p align="center">
  <img src="/images/quickstart-claude-call-tool.png" alt="claude calls context7 tool via sami-mcp-gateway" height="400" />
</p>

You now have a working MCP setup with a single unified endpoint.
